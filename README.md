# KEIBA SIM — 競馬シミュレーター

疑似マネーで馬券を買って遊ぶ競馬シミュレーション。`index.html` をブラウザで開くだけで動く(依存なし)。

## 開催(1 日 3 場)
- JRA と同じく 1 日 3 場 × 12R = 36 レース。週替わりで「東京・京都・新潟」と「中山・阪神・中京」(土日で 1 週)
- 発走時刻は 3 場で 10 分ずつずらして交互に出走(例: 東京1R 10:05 → 京都1R 10:15 → 新潟1R 10:25 → 東京2R …)
- 画面上部の番組表から、どのレースの出馬表も開いて先に馬券を買える
- 「発走」は時刻順で最も早い「馬券を買ったレース」を中継し、それより前の未購入レースは結果だけ確定して自動スキップ
  (馬券を買っていなければ次のレースを見送りで中継)。スキップしたレースの結果も番組表から確認できる
- 全 36 レースが終わると翌開催日へ

## 遊び方
1. 馬柱(近5走の詳細)や出馬表を見て予想。表示は「馬柱/出馬表」タブで切り替え
2. 券種と買い方を選んでカートに追加 → 購入(購入後の取消不可)
3. 「発走!」でレース中継(×1〜×8、スキップ可) → 着順・払戻・収支を確認
4. 1日12レース、12R の次は翌日・別の競馬場。所持金と履歴はブラウザに保存

## 仕様(JRA 準拠)
- 券種と控除率: 単勝・複勝 20% / 枠連・馬連・ワイド 22.5% / 馬単・3連複 25% / 3連単 27.5%
- 買い方: 通常・ボックス・ながし(順序つき券種は軸=1着)・フォーメーション
- 払戻: 100円単位で購入、10円未満切り捨て、最低100円(元返し)
- 複勝: 確定3頭の票数からパリミュチュエル式で算出(人気薄ほど高配当)
- 枠番: JRA 方式(9頭以上で8枠から複数頭)。8頭立て以下は枠連発売なし。ゾロ目は同枠2頭以上のときのみ
- オッズ: 大衆の支持率から算出。大衆は真の勝率をノイズ付きで見積もり、穴馬を買いすぎる(本命・大穴バイアス)
- レース: 0.5秒刻みの物理シミュレーション。能力・スタミナ消費・瞬発力・脚質・展開・距離/馬場適性・馬場状態・斤量・騎手・枠順・当日の出来・出遅れ・不利を反映
- 展開: 逃げ・先行の頭数(+駆け引きのブレ)で前半の速さが決まる。速いと前の馬がバテて差し・追込が届き、遅いと馬群が詰まって前残り。
  勝ち馬の脚質は 逃げ10%・先行48%・差し32%・追込10%。遅い展開では前の馬が7割、速い展開では差し・追込が6割強を勝つ
- 馬名: 実在の命名パターンを参考にした架空の名前(9文字以内)。架空の冠名+外国語 26% / 外国語の組み合わせ 24% / 和名 18% / 文章型 12% / 故事・人物のもじり 20%。著名馬の名前は除外リストで生成しない
- 騎手: 架空の名前が中心で、短期免許の外国人騎手や歴史上の人物を一字変えた名前も少し混ぜる
- 結果はシードで決まるため、リロードしても変わらない
- 同着は扱わない(タイム差で順位を決定)

## 馬柱(近5走)
- 各走は古い順に「その時のクラス・条件で、相手関係の中でどれだけ走れたか」から作る。人気は能力の見立て+前走の印象、着順は当日の出来も加えた走りで決まる
  (1番人気の複勝率 約8割、10番人気以下の勝率 約1%)。2・3着も自然に出る。若い頃ほど未完成
- タイムは走りの良さから計算(勝ち時計=クラス水準+勝ち馬の走り、着差=走りの差)。強い馬ほど速い時計が並ぶ
- 勝ち星は古い戦績に寄る(昇級後に今のクラスで何走か足踏みしている馬が多い)。前走 1 着の馬は約 1 割
- 過去走の競馬場はその週の開催 3 場から。同じ日・同じ場・同じ条件の過去走は「同じレース」として着順・馬番・勝ち時計・相手の名前をそろえ、
  勝ち馬が 2 頭になる組み合わせは別レースに移す。馬柱に「対戦 3番2着」のように今回の出走馬との対戦成績を表示
- 出遅れ・不利(⚠)の走りは実力より着順が悪く出る。人気(大衆)は近走の内容を重く見る(今回と同じ馬場・近い距離・最近の走りほど重視、⚠の走りは割り引き)
- レース名: 重賞は固定カタログ(G1 19 レース+各場の G2・G3。名前・競馬場・距離・年齢/牝馬限定の条件が毎回同じ)。
  実在の重賞をもじった架空の名前(例: 有明記念・卯月賞・宝山記念・多摩大賞典・六甲記念・甲山牝馬S)。特別戦は「○○特別」「○○賞」、3勝クラスは「○○ステークス」
- 各走: 日付・競馬場・人気・レース名/クラス・着順/頭数・走破タイムと勝ちタイム・馬場/距離/馬場状態/馬番・騎手/斤量/馬体重・通過順・上がり3F(1〜3位は①②③)・勝ち馬(勝った時は2着馬)とのタイム差
- 各馬: 通算/当場/芝/ダート/同距離(±200m)/重・不良の成績、前走からの間隔(中N週・休み明け)
- 近走の着順は当日と同じ隠し要素(能力・馬場/距離適性・道悪適性・調子)から生成しているので、予想の手がかりになる
- 戦績はクラスと整合(1勝クラスなら通算1勝、勝つたびに昇級)。デビューは2歳6月以降、新馬戦は2歳デビューのみ、未勝利戦は3歳限定
- 開催日は 2026年10月31日(土)から土日で進む

## 予想家の印
架空の予想家 5 人がそれぞれ ◎○▲△△☆ を打つ(☆は 6 番人気以下の穴)。見ているところが違うので印が割れる。
- 堅田 守(本命党): 人気どころを素直に評価
- 穴井 一発(穴党): 人気に比べて実力が上の馬を狙う
- 数見 理(データ派): 能力指数で序列をつける(的中率が最も高い)
- 坂路 走(調教派): 追い切りの評価を重視
- 土井 芝夫(適性派): コース・距離・馬場の実績を重視
各予想家の ◎ の成績(勝率・複勝率・単勝回収率)を、このブラウザで再生したレースについて記録する

## レース中継(tv.js)
実際のコース形状(直線 2 本 + 半円 2 つ。周長・直線長は競馬場ごと)を 3D 空間に置いて透視投影で描画。
コーナーではラチも馬群も曲がり、内馬場越しに反対側の直線や池・ターフビジョン・スタンドが見える。
カメラはレースの進行に合わせて自動で切り替わる:
ゲート(斜め前から・ゲート開扉)→ サイド追走(外ラチ越し・馬群の広がりに合わせてズーム)→
コーナー(外側やや後方から曲がっていく馬群を追う)→ 向正面は高い位置から俯瞰 →
最後の直線は 入口=ゴール奥からの望遠正面(扇状に広がる馬群)→ 中盤=スタンド屋上から真横に見下ろす(先頭集団が収まるようズーム、順位が見て分かる)→
ゴール前=客席側から真横のアップ(ゴール板を画面に入れる)。馬は画面上の進行方向に合わせて傾けて描く
- 実況: 要所の台詞(先行争い・隊列・1000m通過・3〜4角・直線・ゴール・確定)のあいだも、先頭とリード・2〜3番手・中団・後方・
  位置を上げる馬・1番人気や自分の馬の位置・残り距離・ペースを順番に伝え、途切れずにしゃべり続ける(直線は早口で畳みかける)
- 実況の声: ブラウザの音声合成。人の声に近いものを自動で選ぶ(ニューラル音声 → 高品質版 → Google 日本語 → 標準の順)。声は選択欄で変更可。
  盛り上がる場面ほど速く高く、毎回少し抑揚を揺らす。直線の攻防・ゴールは割り込んで読む。🎙 で声だけオフ、🔇 で全部オフ
- 重賞は発走前にファンファーレ(オリジナルの旋律を Web Audio で合成。G1 は長い版)。スタンドの観客を映し、手拍子と歓声が入る。
  🔊/🔇 ボタンで音のオン・オフ。レース中も観客のざわめきが直線で大きくなる(sound.js)
- 残り 400m から騎手が鞭を入れる(振り上げ → 振り下ろし。手綱だけで追う騎手もいる)
- 中継の横に出馬表(印・単勝・人気・現在の順位・自分の馬券)。「出馬表」ボタンで開閉
- 実況: 先行争い → 隊列(先頭・中団・後方・1番人気の位置)→ 1000m(短距離は 600m)通過タイムとペース判定 →
  3〜4 コーナーで進出する馬 → 直線の攻防(外から伸びる馬・叩き合い・突き放し)→ ゴール(写真判定・着差)→ 確定(勝ちタイム・人気・騎手)
- 馬: 毛色別、ギャロップの脚運び、追い出しで騎手が動く。騎手は勝負服(柄つき)+ 枠色の帽子、ゼッケン
- コース: 芝の刈り目/ダートのハロー跡、内外ラチ、ハロン棒(残り距離)、ゴール板、ゲート、スタンドと観客、ターフビジョン、
  木立と山(遠いほど霞む)、内側にダートコース(JRA と同じ配置)、雨天は雨粒、蹄で舞う芝やダート
- 横位置: 内ラチ沿いを好み、前が詰まると外へ。直線では差し・追込が外へ持ち出す
- テロップ: レース名・タイム・現在地(コーナー名)・残り距離・実況字幕・順位ティッカー・コース全体図・着順掲示板(確定ランプ)
- 自分が買った馬は番号札が赤枠で目立つ

## 較正結果(400レース)

人気別単勝回収率 1番人気 82% → 10番人気以下 31% / 芝1600 勝ちタイム中央値 1:32.4
